<h2>先看题目</h2>
给你一个下标从 0 开始的整数数组 <code>nums</code> ，返回 <code>nums</code> 中满足<em> </em><code>i mod 10 == nums[i]</code><em> </em>的最小下标 <code>i</code> ；如果不存在这样的下标，返回<em> </em><code>-1</code><em> </em>。

<code>x mod y</code> 表示 <code>x</code> 除以 <code>y</code> 的 <strong>余数</strong> 。

&nbsp;

<strong>示例 1：</strong>
<pre><strong>输入：</strong>nums = [0,1,2]
<strong>输出：</strong>0
<strong>解释：</strong>
i=0: 0 mod 10 = 0 == nums[0].
i=1: 1 mod 10 = 1 == nums[1].
i=2: 2 mod 10 = 2 == nums[2].
所有下标都满足 i mod 10 == nums[i] ，所以返回最小下标 0
</pre>
<strong>示例 2：</strong>
<pre><strong>输入：</strong>nums = [4,3,2,1]
<strong>输出：</strong>2
<strong>解释：</strong>
i=0: 0 mod 10 = 0 != nums[0].
i=1: 1 mod 10 = 1 != nums[1].
i=2: 2 mod 10 = 2 == nums[2].
i=3: 3 mod 10 = 3 != nums[3].
2 唯一一个满足 i mod 10 == nums[i] 的下标
</pre>
<strong>示例 3：</strong>
<pre><strong>输入：</strong>nums = [1,2,3,4,5,6,7,8,9,0]
<strong>输出：</strong>-1
<strong>解释：</strong>不存在满足 i mod 10 == nums[i] 的下标
</pre>
<strong>示例 4：</strong>
<pre><strong>输入：</strong>nums = [2,1,3,5,2]
<strong>输出：</strong>1
<strong>解释：</strong>1 是唯一一个满足 i mod 10 == nums[i] 的下标
</pre>
&nbsp;

<strong>提示：</strong>
<ul>
 	<li><code>1 &lt;= nums.length &lt;= 100</code></li>
 	<li><code>0 &lt;= nums[i] &lt;= 9</code></li>
</ul>
<h2>我写的</h2>
我的思路：先创建一个ans数组，再遍历一遍题目给的nums数组，当取到正确的数后，将下表存储在ans数组中，再用三个if语句将结果数组（Tips:求数组中的最小值可用函数*min_element(p, p + n)，就是在p~p+n范围内的最小的数，max类同）
<pre class="pure-highlightjs"><code class="">class Solution {
public:
    int smallestEqual(vector&lt;int&gt;&amp; nums) {
        int count = 0, j = 0;
        vector&lt;int&gt; ans;
        for (int i = 0; i &lt; nums.size(); ++i) {
            if (i % 10 == nums[i]) {
                count++;
                ans.push_back(i);
            }
        }
        if (count == 0)
            return -1;
        if (count == nums.size())
            return 0;
        else
            return *min_element(ans.begin(), ans.end());
    }
};</code></pre>
