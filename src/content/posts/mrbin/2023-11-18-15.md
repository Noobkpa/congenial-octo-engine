<p>本次选取的是某吧中的抗压背锅吧中的一篇帖子,帖子标题是“faker 你要毁了lpl么？”。爬取的目标是帖子里面的回复内容。</p>



<p>PYTHON代码如下：</p>



<div>
<pre>import csv<br />import requests<br />import re<br />import time<br /><br /><br />def main(page):<br />    url = f'https://tieba.baidu.com/p/8713988388?pn={page}'<br />    headers = {<br />        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/106.0.0.0 Safari/537.36'<br />    }<br />    resp = requests.get(url, headers=headers)<br />    html = resp.text<br />    # 评论内容<br />    comments = re.findall('style="display:;"&gt;                    (.*?)&lt;/div&gt;', html)<br />    # 评论用户<br />    users = re.findall('class="p_author_name j_user_card" href=".*?" target="_blank"&gt;(.*?)&lt;/a&gt;', html)<br />    # 评论时间<br />    comment_times = re.findall('楼&lt;/span&gt;&lt;span class="tail-info"&gt;(.*?)&lt;/span&gt;&lt;div', html)<br />    for u, c, t in zip(users, comments, comment_times):<br />        # 筛选数据,过滤掉异常数据<br />        if 'img' in c or 'div' in c or len(u) &gt; 50:<br />            continue<br />        csvwriter.writerow((u, t, c))<br />        print(u, t, c)<br />    print(f'第{page}页爬取完毕')<br /><br /><br />if __name__ == '__main__':<br />    with open('01.csv', 'a', encoding='utf-8') as f:<br />        csvwriter = csv.writer(f)<br />        csvwriter.writerow(('评论用户', '评论时间', '评论内容'))<br />        for page in range(1, 8):  # 爬取前7页的内容<br />            main(page)<br />            time.sleep(2)</pre>
