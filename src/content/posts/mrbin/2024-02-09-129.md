一道在力扣上的简单问题，我写了几十行代码，别人几行就搞定了

虽然时间上没区别，但不得不感叹代码的可读性真的很重要，既简洁又高效的才是好程序~

先看问题：

桌上有 <code>n</code> 堆力扣币，每堆的数量保存在数组 <code>coins</code> 中。我们每次可以选择任意一堆，拿走其中的一枚或者两枚，求拿完所有力扣币的最少次数。

<strong>示例 1：</strong>
<blockquote>输入：<code>[4,2,1]</code>

输出：<code>4</code>

解释：第一堆力扣币最少需要拿 2 次，第二堆最少需要拿 1 次，第三堆最少需要拿 1 次，总共 4 次即可拿完。</blockquote>
<strong>示例 2：</strong>
<blockquote>输入：<code>[2,3,10]</code>

输出：<code>8</code></blockquote>
<strong>限制：</strong>
<ul>
 	<li><code>1 &lt;= n &lt;= 4</code></li>
 	<li><code>1 &lt;= coins[i] &lt;= 10</code></li>
</ul>
&nbsp;
<h2>我的方法</h2>
<pre class="pure-highlightjs"><code class="">class Solution {
public:
    int minCount(vector&lt;int&gt;&amp; coins) {
        int ans = 0;
        for (int i = 0; i &lt; coins.size(); ++i) {
            while (coins[i] % 2 == 0) {
                coins[i] -= 2;
                ans++;
                if (coins[i] &lt;= 0)
                    break;
            }
            while (coins[i] != 1 &amp;&amp; coins[i] % 2 == 1) {
                coins[i] -= 2;
                ans++;
            }
            if (coins[i] == 1) {
                ans++;
                continue;
            }
        }
        return ans;
    }
};</code></pre>
<h2>大佬的方法</h2>
<pre class="pure-highlightjs"><code class="">class Solution {
public:
    int minCount(vector&lt;int&gt;&amp; coins) {
        int cnt = 0;
        for(auto&amp; num : coins) {
            cnt += num / 2 + num % 2;
        }
        return cnt;
    }
};</code></pre>
